# TrueLens Frontend

React 19 + Vite web dashboard for TrueLens media verification.

## Features
- Drag & Drop media upload (Image, Audio, Video).
- Dynamic Verdict Banner & Risk Score (0–100).
- GenAI Evidence Explanation Card.
- Interactive ELA Heatmap Viewer, Spectrogram Visualizer, and Video Keyframe Gallery.
- C2PA Content Credentials & Provenance Timeline Card.
- Local SQLite Analysis History Drawer.

## Development & Build

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev -- --host 127.0.0.1 --port 3000

# Build production bundle
npm run build
```
